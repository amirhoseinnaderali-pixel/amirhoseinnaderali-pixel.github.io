# Amirhossein Research Website

GitHub Pages-ready static personal research website.

## Publish
1. Create a public repository named `YOUR_USERNAME.github.io`.
2. Upload `index.html`, `styles.css`, and your final `cv.pdf`.
3. Go to Settings → Pages → Deploy from branch → main → /root.
4. Replace `YOUR_EMAIL@example.com` with your real email.
5. Replace the LinkedIn placeholder with your actual profile.

No build step is required.
