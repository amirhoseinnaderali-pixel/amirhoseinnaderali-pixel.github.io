Efficient Reasoning in Language Models
GitHub ↗
  • Built a controlled C0–C6 benchmark using 100 HumanEval-derived tasks, three seeds, and isolated hidden-test evaluation.
  • Execution-based feedback increased the observed hidden-test pass rate from 72% to 87% at 2.2× token cost.
Graph-Structured Reasoning
GitHub ↗
  • Compared graph aggregation against first-candidate, random, consensus, and similarity-based selectors on identical candidate sets (EXP-001 protocol).
  • Graph aggregation reached 61.5% versus 55.0% for the baseline selector, and 71.0% when combined with objective verification.
Training vs. Inference Compute
GitHub ↗
  • Designed a frozen A0–A4 benchmark varying the compute split from 10% training / 90% inference to 90% training / 10% inference.
  • Observed hidden accuracies were 92%, 91%, 89%, 85%, and 68%, respectively; interpreted as benchmark- and model-specific, not a general law.

Selected LLM Engineering Projects

DPO Distributed Training Benchmark

Compared PyTorch FSDP, DeepSpeed ZeRO-2, tuned ZeRO-2, and ZeRO-3 for DPO using TinyLlama-1.1B and HH-RLHF on two T4 GPUs. Tuned ZeRO-2 reached 4.31 samples/s, 61.4% above baseline, and reduced training time from 336 to 208 seconds at 3.62 GB; released a reproducible notebook.

DistillLlama-Curriculum

Built a four-stage curriculum (instruction tuning, APPS/IOI, debugging, and Magicoder-Evol) for DeepSeek-R1-Distill-Llama-8B using LoRA and Unsloth on a T4.

Phi-4 → Qwen2.5-0.5B Distillation

Implemented two-stage logit distillation using top-50 teacher logits, cross-entropy and KL loss (T=1.5), with DeepSpeed ZeRO-2.

Qwen2.5-Coder-14B PEFT

Applied 4-bit LoRA (r=16, α=32) using Unsloth on a single 14 GB T4, with approximately 12–13 GB peak VRAM.
